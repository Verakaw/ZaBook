# ЗА-Бронь

Учебное демо бронирования загородных домов. Название обыгрывает «забронь» и «за бронь»: пользователь выбирает домик на локальной схеме территории, сравнивает удобства и сохраняет бронь.

## Запуск

ES-модули браузера нужно запускать через HTTP-сервер, а не двойным кликом по `index.html`:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`.

## Возможности

В проекте есть единый массив `COTTAGES`, из которого строятся карта, список домов, карточка и фильтры. Схема территории использует локальное изображение `map.png`; поверх него расположены интерактивные кнопки домов. Дома находятся возле дорожек и тропинок, а не в озере или лесной зоне.

Доступны фильтры по вместимости и цене, синхронный список домов, статусы «Свободен», «Выбран» и «Занят», карточка выбранного дома, удобства, этажность, расчёт стоимости и форма бронирования. Гости проверяются по вместимости выбранного дома, ночи — в диапазоне от 1 до 30.

Раздел «Мои брони» позволяет сохранять, отменять и очищать собственные брони. Два дома с `initiallyBusy: true` всегда заняты, не попадают в пользовательские брони и недоступны для выбора или отмены.

## LocalStorage

Брони записываются сразу после подтверждения в `localStorage` по ключу:

```text
cottage_bookings_v1
```

При загрузке записи восстанавливаются. Повреждённый JSON или JSON неверной структуры сбрасывается с понятным сообщением, после чего приложение продолжает работать.

## Доступность и адаптивность

Домики на карте и кнопки в списке доступны с клавиатуры через Tab, Enter и Space. Используются видимый `:focus-visible`, `aria-label`, `title`, текстовые статусы, `aria-live`, `aria-describedby` для ошибок полей и семантические элементы `header`, `main`, `section`, `form`, `label`, `button`.

Интерфейс адаптирован для 360, 768 и 1280 пикселей. Карта сохраняет пропорции исходного изображения, а список и форма перестраиваются на узких экранах и при увеличении масштаба браузера.

## Ограничения демо

Это не настоящее бронирование: нет авторизации, сервера, оплаты, календаря доступности и синхронизации между устройствами. Брони сохраняются только в localStorage текущего браузера. Все изображения локальные: карта `map.png`, эмодзи и CSS. Внешние шрифты, CDN и API не используются.

## Нейросеть и полезные промпты

Проект можно использовать как учебный пример генерации и проверки интерфейса нейросетью. Полезные промпты:

> Проверь vanilla JS-приложение бронирования на ошибки состояния, доступность клавиатуры и гонки при двойном клике. Дай конкретные исправления по файлам, не добавляя фреймворки.

> Проведи визуальный аудит адаптивности интерфейса на 360, 768 и 1280 пикселях. Сохрани природную палитру и предложи точечные изменения CSS с объяснением.

> Проверь обработку повреждённого localStorage, фильтров и ограничения вместимости. Не меняй публичные названия полей и не добавляй сервер.

## GitHub Pages

Сборка не нужна. Публикуемая структура репозитория:

```text
index.html
styles.css
app.js
map.png
.nojekyll
README.md
```

Файл `.nojekyll` должен быть пустым и находиться в корне репозитория. Создать его можно командой:

```bash
touch .nojekyll
git add .nojekyll
```

В GitHub откройте `Settings → Pages`, выберите `Deploy from a branch`, ветку `main` или `master` и папку `/ (root)`, затем нажмите `Save`. GitHub Actions и сборщик не нужны.

Перед публикацией проверьте, что `map.png` закоммичен, имя файла совпадает по регистру, а сайт открывается через локальный HTTP-сервер. В DevTools → Console не должно быть необработанных ошибок.

Яндекс Карты и 3D-превью в текущую версию не входят: оставлена простая автономная схема на локальном изображении.
